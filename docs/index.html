143 tools. 44 ask before they run.

mq-mcp is the execution runtime of the MQ stack: a local MCP server for macOS that exposes bounded tools with safety metadata, review, memory and an OpenAI bridge. Every tool has a class in tool_contracts.json, and the bridge asks for consent before any tool that writes or acts beyond the screen. Version 2.3.1.

Where it sits in the stack

mq-mcp runs tools. Planning, routing and dry-runs belong in mq-agent.

  • mq-agentPlans, routes, dry-runs and holds the approval UX.
  • mq-mcpExecutes bounded tools, records reviews and memory, bridges to OpenAI.
  • repo-signalScores repo health.
  • mq-halTurns the results into operator reports.

How it runs

The server speaks stdio by default; mq-mcp serve --host --port switches to HTTP or SSE. Bridget is the terminal client.

Request path

bridget "prompt"
  └── mq-mcp/bridge.py
      → OpenAI Chat Completions
      → consent check (bridget_safety.py)
      → MCP tool call → server.py

ask "prompt"
  └── mq-mcp/ask.py
      → OpenAI Responses API
      → vector store search

Install

Needs uv. The script installs the mq-mcp command and the Bridget launcher, keeps any existing .env, and runs doctor.

git clone https://github.com/MCamner/mq-mcp
cd mq-mcp
./scripts/install.sh

mq-mcp doctor
mq-mcp tools
mq-mcp serve
